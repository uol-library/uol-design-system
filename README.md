# Design System assets and examples

This reopository uses the [jekyll-theme-uol](https://github.com/uol-library/jekyll-theme-uol) jekyll theme to create a set of web pages to illustrate some design system components.

It also uses [shuji](https://github.com/paazmaya/shuji) to decompile the assets in Design System to give some idea of how the SCSS is put together (while we don't have access to the source repository in DevOps)
